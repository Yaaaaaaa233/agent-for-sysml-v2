===== 5.1 矩阵自动反映了什么（变更前 vs 变更后逐行比对）=====
矩阵有变化的行：1 行（其余 3 行逐字段相同）
[
  {
    "requirement": "REQ-CRUISE-ENDURANCE",
    "before": {
      "text_short": "巡航时间不低于 4 小时",
      "status": "satisfied-and-verified"
    },
    "after": {
      "text_short": "巡航时间不低于 5 小时",
      "status": "satisfied-and-verified"
    }
  }
]

说明：矩阵的 status 由 satisfiedBy / verifiedBy 结构决定，本次变更只改字段值与
文本，不改结构，所以 status 不变、text_short 从 4 小时变成 5 小时——矩阵确实跟着
事实来源（IR）自动重算，不需要手工维护表格。

| `REQ-MISSION-ENDURANCE` | MissionEndurance | 任务级续航：共轴八旋翼须按指定任务剖面完成起飞、巡航与安全返航。 | `PART-POWER-CHAIN` | `ACT-SIM-ENDURANCE` | satisfied-and-verified |
| `REQ-POWER-BUDGET` | CruisePowerBudget | 巡航稳态下整机电功率不超过电池可持续放电功率上限。 | `PART-POWER-CHAIN` | `ACT-SIM-ENDURANCE` | satisfied-and-verified |
