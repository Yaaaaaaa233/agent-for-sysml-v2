## 4. 升级安装怎么做（**需用户在自己机器上重跑**）

本任务的沙箱**只允许写工作区**，对 `~/.dsh` 的任何写入都会被拒绝（`Operation not permitted`），
所以本文件只证明「脚本能正确打印配置」，**不代表 `~/.dsh` 已被改动**。

升级安装（例如二期新增了两份 skill）：

```bash
cd sysml-modeling-agent
./install.sh            # 默认符号链接模式：已存在的 skill 跳过，缺的补上
```

- **符号链接模式**（默认）：链接指向仓库目录，仓库里的 `SKILL.md` 更新后**立即生效**，无需重跑。
- **复制模式**（`--copy`）：副本是静态的，升级需先删旧副本（`rm -rf ~/.dsh/skills/<name>`）再重跑。
- **MCP 条目**：`install.sh` **不代改** `cordis.yml`，升级后按 §1 打印的片段核对
  `command` / `args` / `cwd` 三行是否仍是当前路径（换过仓库目录时必须更新）。
