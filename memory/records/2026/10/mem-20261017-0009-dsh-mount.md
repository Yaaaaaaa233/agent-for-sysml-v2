## 内容

把 MCP server 挂进 DSH profile 只能走 **`cordis.patch.yml` 补丁层**：手工写 `cordis.yml` 会被应用回写
冲掉。profile 行里 `command` 用 `file:///…/dsh-mcp-client/lib/index.js` 绝对路径并设
`failOnStartupError: true`；全局 mcp 行保持 `disabled: true`，只用 preset 行。

## 为什么

2026-10-17 实测：手写 `cordis.yml` 被回写；profile 里 `@deepseek-ai/dsh-mcp-client` 副本过期导致工具不
出现，换成 file:// URL + `failOnStartupError` 后 `mcp__sysml-agent__*` 才稳定出现。README 与
`docs/本机挂载试用指引.md` 都记了这条。

## 用法

- 工具在会话里消失：先看 preset 行 `fiber.state` 与 `/diagnostics?mcpSelfTest=1`；
- 改挂载只改 patch 文件，不要手写 cordis.yml；
- 换机器跑 `install.sh --print-config` 生成片段。
